# NOVA CLIENT
### The Next Generation Minecraft Launcher

**Premium Design. Powerful Customization. One Launcher.**

Nova Client is an independently developed Minecraft launcher for Windows, designed to deliver a modern, customizable, and streamlined Minecraft experience.

Our goal is to combine game management, mod customization, performance tools, and a premium user interface into one application.

> **Development Status:** Early development / Pre-release  
> **Platform:** Windows  
> **Supported Editions:** Minecraft Java Edition and Bedrock Edition (different levels of integration)

---

## 💜 About Nova Client

Nova Client is being developed as a premium alternative to traditional Minecraft launchers.

Featuring a near-black interface, subtle purple glowing accents, and customizable game profiles, Nova aims to make managing and playing Minecraft easier.

The project is currently in active development, with features being implemented and tested incrementally.

## ✨ Current Features

The Nova Client development builds include:

- **Premium Desktop Interface** — Dark-themed launcher with violet accents and animated UI components.
- **Java / Bedrock Selection** — Switch between Java and Bedrock launcher workflows.
- **Game Profiles** — Create and manage separate Java Edition configurations.
- **Mod Management** — Import, enable, disable, and organize local Minecraft mods.
- **Modrinth Integration** — Search for and install compatible community content.
- **Modpack Importing** — Support for importing `.mrpack` files.
- **Custom Game Directories** — Configure isolated Minecraft installations.
- **Launch Console** — View game initialization messages and diagnostic output.

Some functionality remains experimental and requires additional testing.

## 🔐 Microsoft Authentication

Nova Client is working toward supporting secure Microsoft account authentication through Microsoft's official OAuth 2.0 authentication system.

The intended authentication process will:

1. Open Microsoft's official sign-in experience.
2. Allow users to authenticate with their own Microsoft accounts.
3. Obtain authorized authentication tokens.
4. Verify Minecraft Java Edition ownership through Minecraft Services.
5. Allow eligible users to launch Minecraft directly from Nova Client.

**Nova Client does not request users' Microsoft passwords.**

Access to Minecraft Services is subject to Microsoft's and Minecraft's application authorization requirements. Direct authenticated launching is not yet a verified, production-ready feature.
